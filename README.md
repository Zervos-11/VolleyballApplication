# Volleyball analytics research code and evidence

This private repository contains code, numerical review records and result reports for Michael Zervos's honours research prototype. **The thesis manuscript is provided separately and is not stored in this repository.**

Start with the [supervisor review guide](SUPERVISOR_REVIEW.md), [primary feasibility result](DELIVERABLES/HONOURS_U5_PRIMARY_FEASIBILITY_RESULT.md), [S3 P34 interval result](DELIVERABLES/HONOURS_U5_S3P34_REPORTED_LIVE_INTERVAL_RESULT.md), and [data management record](DELIVERABLES/DATA_MANAGEMENT.md). The dated research handoff describes an earlier ZIP package; its thesis references are historical and the manuscript is not included here.

Run `python scripts/check_honours_evidence_package.py --code-review-snapshot` to verify included primary-match numerical records. Source videos, identifiable frames, model weights and local caches are omitted.
