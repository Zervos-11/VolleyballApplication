# Reusing the earlier ProVolley–UTS labels

The five pilot rallies have **69 saved, annotator-complete frame records**. They remain in `data/matches/yt_FqE5pTJqx8g/pilot/player_annotations/` and do not need to be redrawn. “Complete” here records that the annotator accounted for the players; it does not certify each foot contact or court projection for a final metric.

| Earlier rally | Set and score point | Saved frames | In the later 18-point score sample? |
| --- | --- | ---: | --- |
| R1 | Set 1, point 10 | 10 | No |
| R2 | Set 2, point 2 | 12 | **Yes**; the review queue links to these existing labels |
| R3 | Set 2, point 17 | 12 | No |
| R4 | Set 3, point 2 | 26 | No |
| R5 | Set 3, point 20 | 9 | No |

The 18-point sample was later selected from score outcomes within each set and winner group, before spatial metric scoring. That sampling rule happened to select only R2 from the five earlier temporal pilots. It does **not** erase the other four or make their labels invalid: they remain the primary development and feasibility evidence. The separate D79 and AoEP labels test tracking on other recordings, so they cannot supply ProVolley–UTS point outcomes.

For the agreed frozen-sample comparison, each sampled point needs an eligibility and source review record, but it does not require hand-labelling every video frame. Frames used for final court metrics need checked identities, visible floor contacts, and adequate calibration. The existing 69 pilot frames should be used first to assess how much of that review can be automated and whether a larger outcome comparison is feasible. If the final study is narrowed to the pilot rallies, report the sampling change, small group sizes, and selection limits explicitly; do not present those five as the balanced 18-point sample.
